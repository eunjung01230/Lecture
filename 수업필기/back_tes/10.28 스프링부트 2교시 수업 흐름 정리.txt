10.28 2교시 수업 흐름 정리 

1. Application 실행
-> yaml (환경설정 읽음)
2. Spring Boot / Tomcat 실행 (: Spring을 쓰면 2번 상세 과정이 숨겨지는 것)
-> Spring 컨테이너 생성= IoC 컨테이너
-> Controller 등록(@Component, @Controller, @Service 등 확인)
[필요한 객체(Bean) 생성 및 등록 -> 객체 간 의존성 연결(DI) ->애플리케이션 실행 준비]
-> Servlet 등록 및 초기화(서버시작과정이나 첫 요청시)
3. 브라우저에서 index.html 요청
4. 사용자가 버튼 클릭 또는 폼 제출
->Servlet이 처리할 HTTP 요청 발생 
5. Tomcat이 요청을 Servlet에 전달
->Spring MVC가 알맞은 Mapping 확인
6. Controller 메서드 실행
7. Controller가 "result" 반환
-> View 이름 반환
8. templates/result.html을 찾아 HTML 생성
9. 브라우저에 HTTP 응답
10. 사용자가 결과 화면 확인
==============================
Tomcat = 음식점 운영 및 직원 관리
Servlet = 주문을 처리하는 직원
HTTP 요청 = 손님이 주문하는 행위
Controller = 주문 종류에 따라 실행할 업무를 구분하는 담당자

Spring Framework: IoC, DI, MVC 등 애플리케이션 개발에 필요한 기능을 제공한다.
Spring Boot: Spring을 편리하게 사용할 수 있도록 설정과 실행 환경을 자동으로 구성한다.
Tomcat: HTTP 요청을 받고 Servlet을 실행·관리한다.
Controller: 개발자가 작성한 요청 처리 메서드를 실행한다.

실행원리 

컴파일 = 번역기 
.java로 작성 jdk가 알아서 class 파일로 변환 / 컴퓨터가 이해할 수 있게 (class = 컴이 이해하는 파일)
jvm_클래스 로더를 작동 컴이 동작할 수 있는 class를 메모리에 업로드 하는 것 
Java 의 실행 과정
        *  1. Java 코드를 작성한다. (.java)
        *  2. JDK 설치 시 들어있는 Javac(컴파일러)가
        *      .java 파일을 .class 파일로 번역한다.
        *  3. JVM 이 .class 파일을 로드하고 실행한다.
        *  4. JVM 은 바이트 코드를 해것하여 각 OS에서
        *    실행 가능한 기계어로 변환한다.
        *  5. 변환 된 기계어를 실행한다.

리터럴은 "값"을 의미한다. 
리터럴은 순수한 값으로서 정수, 실수, 문자, 문자열, 논리 등으로 구성이 되어 있다. 
변수 : 프로그래밍에서 공간의 개념 
 - - - - - - - - - - - - - - - 
자료형 크게 4가지 있음 
1바이트는 8개의 공간(bit) 을 가짐 이 공간에는 1 또는 0 들어가지 (= 1byte=8bit)
1 byte 가 담을 수 있는 값의 범위는 (-128 ~ 127) 8자리 이진법의 한계치 / 바이트가 커질수록 제곱수가 증가 

숫자형 - 정수를 담는 자료형
     byte b = 10; / = 1 byte
     short s = 10; /  = 2 byte 
     int i = 10; /  = 4 byte 
     long l = 10; /   = 8 byte 

숫자형 - 실수를 담는 자료형 / 정수보다 정확한 수 / 1, 2, 3, 바이트 없음 10 = 10.0(소수를 저장해야해서 기본값이 더 큼)
     float f = 3.14f; / = 4 byte
     double d= 3.14; / =8 byte

문자형 
    char ch = 'ㅎ'; / 무조건 1글자 

문자열 // 같은 영역 ({}) 내부에서 동일한 변수명을 사용하는 것은 불가능하단다.

형변환( Type Conversion) 데이터 타입 (자료형) 을
        *   다른 데이터 타입으로 변환하는 과정을 의미한다.
        *   형변환은 두 가지 방식이 있다.
        *   1. 암시적(묵시적) 형변환
        *   2. 명시적 형변환

double dnum = 99.99; // 8byte
int inum = (int)dnum;  // 4byte (int)로 명시적 형변환을 통해 자료형을 변환 8->4 넘침 강제 줄이기 
// 디버깅용 출력 구문
System.out.println("dnum = " + dnum);
System.out.println("inum = " + inum);

// 암시적(묵시적) 형변환 
int num2 = 100; // 4byte
double dnum2 = num2;  // 8byte = (double)num2; 4->8은 가능이여서 (double)생략 회색글씨

명시적 형변환은 데이터 손실 가능성이 존재하기 
        *   때문에 컴파일러가 번역 시에 Error를 발생시킨다.
        *   데이터 손실을 감수하면서 형변환을 할 때는 
        *   명시적으로 작성을 해주어야만 한다.

연산자 
산술연산  (+, - , * , %, / )
- % 프로그래밍에서는 모드 연산 이라는 것이 추가된다. 나머지를 구하는 연산자
비교연산  ( == , != , < , > , <= , >= )
- 두 값을 비교하여 참 / 거짓을 반환하는 연산자
논리연산  ( &&(and) , ||(or), !(not) )
- 하나 이상의 "조건을 결합" 하여 최종적인 참 또는 거짓을 평가한다.
증감 연산  (++(증가) , --(감속) )
- 변수의 값을 1씩 증가 시키거나 감소 시키는 연산자

Spring Boot 프로젝트를 생성하면 일반적으로 @SpringBootApplication이 선언된 Application 클래스가 생성된다.

Application의 main() 메서드를 실행하면 SpringApplication.run()이 호출되고 Spring Boot가 시작된다.

실행 과정에서 환경설정을 읽고, IoC Container(ApplicationContext)를 준비하여 Bean을 생성하고 의존성을 주입한다. 웹 애플리케이션이라면 내장 Tomcat도 시작되어 HTTP 요청을 받을 준비를 한다.

이후 브라우저에서 요청이 들어오면 Tomcat이 요청을 받아 Spring MVC의 DispatcherServlet으로 전달한다. DispatcherServlet은 요청을 처리할 Controller를 찾고, 필요에 따라 Service와 Repository를 거쳐 처리 결과를 응답한다.

static은 정적 리소스, templates는 서버에서 처리할 화면 템플릿, application.yaml은 환경설정 파일이다.

서버 시작: main() → SpringApplication.run() → Spring 환경 및 Tomcat 준비
요청 처리: 브라우저 → Tomcat → DispatcherServlet → Controller → 응답
Spring IoC/DI와 AOP는 사라진 게 아니라 Spring Boot 안에서도 그대로 동작
단, Spring Boot가 복잡한 초기 설정을 자동화

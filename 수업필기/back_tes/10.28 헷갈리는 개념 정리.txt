Servlet
- 클라이언트의 HTTP 요청을 처리하고 응답을 생성하는 Java 객체
- Servlet Container(Tomcat)에 의해 생성되고 관리됨

Tomcat
- Servlet을 생성·관리하고 실행하는 환경(Servlet Container)
- HTTP 요청을 받아 알맞은 Servlet에 전달하고 응답을 클라이언트에게 반환함

기존 Servlet 방식
- 개발자가 HttpServlet을 상속받아 Servlet 클래스를 직접 작성
- doGet(), doPost() 등의 메서드에서 HTTP 요청을 처리

Spring MVC 방식
- Spring이 제공하는 DispatcherServlet이 공통으로 HTTP 요청을 받음
- DispatcherServlet이 알맞은 Controller 메서드를 찾아 호출
- 개발자는 주로 @Controller, @GetMapping, @PostMapping 등을 사용하여 요청 처리 코드를 작성

기존 Servlet 방식
브라우저 -> Tomcat -> 개발자가 작성한 Servlet -> doGet() / doPost() ->HTTP 응답

Spring MVC 방식
브라우저 -> Tomcat -> DispatcherServlet -> Controller -> Service (필요한 경우) -> HTTP 응답

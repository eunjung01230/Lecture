forward - redirect 
요청에 관한 값을 정확히 명시해 주지 않으면 새로고침 할때마다 계속 반복(예: 회원가입)
그래서 redirect 필요 기본은 forward라 계속 요청됨 근데 redirect 주소가 바뀌면 방지 가능 

redirect 한번 요청이 갔다가 돌아왔다가 다시 요청됨 그 곳으로 다시 
forward 처음 요청은 model에 있는 곳으로 다시 재요청은 / 여기로 

Forward(포워드): 서버 내부에서 요청을 다른 대상으로 전달하는 방식이다. 새로운 HTTP 요청을 만들지 않고 기존 요청을 그대로 사용한다.
= 기존 요청을 유지하면서 서버 내부에서 전달 (URL 유지)
Redirect(리다이렉트): 서버가 브라우저에 다른 URL로 이동하라고 응답하는 방식이다. 브라우저가 해당 URL로 새로운 HTTP 요청을 보낸다.
= 브라우저가 새로운 요청을 보내도록 이동 (URL 변경)
-----
Forward는 기존 요청을 유지하고, Redirect는 새로운 요청을 발생시킨다는 것이 핵심 차이
결론 
Forward 자체가 요청을 반복시키는 것은 아니지만, POST 처리 결과를 직접 반환하면 새로고침 시 POST가 재전송될 수 있다.
Redirect는 회원가입, 게시글 작성, 결제 등 데이터 저장 이후 새로고침으로 인한 중복 요청을 방지하기 위해 사용한다.

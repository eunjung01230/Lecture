객체란? 클래스를 통해 만든 하나의 실제 new로 실제 만들어진 값? 것? 
객체는 클래스라는 설계도를 바탕으로 메모리에 실제로 만들어진 데이터와 기능의 묶음
클래스 = 어떤 정보를 가질지 정한 설계도
객체 = 그 설계도로 실제 만들어진 것 / 값 = 데이터 덩어리 

그 객체 안에 있는 것을 사용하겠다
String str = "apple";

str.length();
str이 가리키는 객체 apple의 length 값을 출력하겠다

String = 클래스 = 파일? 
자바가 기본으로 가지고 있는 String이라는 하나의 파일 안에 
length(); length(); 등 각자의 기능을 가진 메서드를 가지고 있다

String result = trimStr.trim();
trimStr이 가리키는 String 객체의 trim() 메서드를 호출하고, 앞뒤 공백이 제거된 String 자료형의 결과값을 반환한다.

무언가를 담기 위해서는 무조건 변수가 필요함 

실제 흐름

[준비]
Application : new Player("1P") ──→ Player : new Balloon()  (풍선 3개, 높이 0)
Application : new Player("2P") ──→ Player : new Balloon()
Application : new Game(1P, 2P)    → Game : 두 플레이어 기억
Application : game.start()        → Game : "게임을 시작합니다!" 출력
                                   ↩ Application으로 돌아옴

[한 턴 반복 while]
① Application : game.getCurrentPlayer() → Game : "1P야"     ↩
② Application : game.printStatus()      → Game : 상태 출력  ↩
③ Application : 메뉴 출력, 번호 입력
④ Application : now.up()  ──→ Player : balloon.up() ──→ Balloon : 높이 +1
                                                          ↩ ↩ Application으로 돌아옴
⑤ Application : game.isOver() → Game : "아직 안 끝났어"   ↩
⑥ Application : game.nextTurn() → Game : turn 1 → 2     ↩
   → ①로 돌아감 (이번엔 2P)

[끝]
⑤에서 풍선 0개면 → game.printWinner() → Game : "승자는 1P!" 출력
                 → Application : break → main 끝 → 프로그램 종료

종료 메세지

Application이 출력하는 "게임을 종료합니다."는 9번을 눌렀을 때만 나옵니다. 누군가 이겨서 끝나면 Game.printWinner()가 승자를 출력하고, Application은 break로 반복문을 나와 아무 말 없이 끝납니다.

----------------------------------------------------------------------------------------------------------------
코드를 실행 순서(Application → Game → Player → Balloon)대로 설명합니다.

1. 전체 구조

Application (지휘자 : 입력 받고 메세지 보내기)
   │
   ├──→ Game (심판 : 턴 순서, 상태 출력, 승패 판정)
   │      └─ player1, player2 를 기억
   │
   └──→ Player (선수 : 이동, 공격, 풍선 불기)
          └──→ Balloon (풍선 : 높이·개수를 실제로 바꿈)
- 누가 누구를 가지고 있나: Game은 Player 2명을, Player는 자기 Balloon 1개를 가지고 있습니다.
- 누가 실제로 값을 바꾸나: 높이와 풍선 개수는 Balloon만 바꿉니다. Player와 Game은 풍선에게 시키거나 물어보기만 합니다.
- 누가 입력을 받나: Application만 입력을 받습니다. 다른 클래스는 메세지를 받으면 자기 일만 하고 Application으로 돌아옵니다.

2. 실행 흐름

[프로그램 시작]
시작 화면 출력 → 번호 입력
 ├─ 9 → "프로그램을 종료합니다." → 끝
 ├─ 그 외 → "잘못된 번호입니다." → 시작 화면 다시
 └─ 1 → 새 판 준비
          new Player("1P") → 안에서 new Balloon()  (높이 0, 풍선 3개)
          new Player("2P") → 안에서 new Balloon()
          new Game(1P, 2P)
          game.start() → "게임을 시작합니다!"

[한 턴]
① game.getCurrentPlayer() / getOpponent() → 이번 차례(now), 상대(enemy)
② game.printStatus() → 두 사람 높이·풍선 출력
③ 행동 입력
④ now에게 메세지  → Player → Balloon 순서로 처리
⑤ game.isOver()?
     ├─ 예 → game.printWinner() → 시작 화면으로
     └─ 아니오 → game.nextTurn() → ①로 (상대 차례)

예시: 1P(높이 2)가 땅에 있는 2P(높이 0)를 공격

Application : now.attack(enemy)
  → Player(1P).attack : 내 높이 2, 상대 높이 0
       높이 0인가? 아니오 / 2 ≤ 0인가? 아니오 → 공격 성공
       → enemy.getBalloon().pop()
            → Balloon(2P).pop : count 3 → 2, "펑! 남은 풍선 2개"
  ↩ Application으로 돌아옴
Application : game.isOver() → 2P 풍선 2개 → false
Application : game.nextTurn() → turn 1 → 2

3. 클래스별 코드 설명

Application.java: 입력과 반복

시작 화면 while (Application.java:48)
int menu = sc.nextInt();
if (menu == 9) { ... return; }      // main 자체를 끝냄 → 프로그램 종료
if (menu != 1) { ... continue; }    // 아래를 건너뛰고 시작 화면 다시

새 판 준비 (Application.java:67)
Player player1 = new Player("1P");
Player player2 = new Player("2P");
Game game = new Game(player1, player2);
시작 화면 반복문 안에 있어서, 1번을 누를 때마다 새로 만들어집니다. 그래서 다시 하면 풍선 3개, 높이 0, 불기 횟수 0으로 시작합니다.

게임 진행 while (Application.java:74)
Player now = game.getCurrentPlayer();
Player enemy = game.getOpponent();
now와 enemy는 새 플레이어가 아니라 이미 만든 player1, player2를 가리키는 이름입니다. 1P 차례면 now가 player1, 2P 차례면 now가 player2가 됩니다. 그래서 switch에서는 1P인지 2P인지 몰라도 now.up() 한 줄로 처리할 수 있습니다.

반복문을 빠져나가는 세 가지 방법

┌──────────────┬────────────────────────────────┬─────────────────┐
│     코드     │              의미              │     쓰인 곳     │
├──────────────┼────────────────────────────────┼─────────────────┤
│ return       │ main 자체를 끝냄 → 프로그램    │ 9번             │
│              │ 종료                           │                 │
├──────────────┼────────────────────────────────┼─────────────────┤
│ break        │ 가장 가까운 while 하나만       │ 승자가 나왔을   │
│ (switch 밖)  │ 빠져나감 → 시작 화면으로       │ 때              │
├──────────────┼────────────────────────────────┼─────────────────┤
│ continue     │ 이번 바퀴의 나머지를 건너뛰고  │ 잘못된 번호 (턴 │
│              │ 다시 처음으로                  │  안 넘김)       │
└──────────────┴────────────────────────────────┴─────────────────┘

switch 안의 break는 switch만 빠져나가고 while은 계속됩니다.

Game.java: 심판

private Player player1;
private Player player2;
private int turn = 1;       // 1 = 1P 차례, 2 = 2P 차례

├────────────────────┼──────────────────────────────────────────────┤

Game은 풍선 개수를 물어보기만 합니다(getBalloon().getCount()). 직접 바꾸는 코드는 없습니다.

Player.java: 선수

private String name;
private Balloon balloon = new Balloon();   // 플레이어가 만들어질 때 자기 풍선도 같이 만들어짐

┌───────────────────┬──────────────────────────────────────────────┐
│      메서드       │                     설명                     │
├───────────────────┼──────────────────────────────────────────────┤
│ getName(),        │ 다른 객체가 이름과 풍선을 물어볼 때 사용.    │
│ getBalloon()      │ 필드가 private이라 이 메서드를 통해서만 볼   │
│                   │ 수 있음                                      │
├───────────────────┼──────────────────────────────────────────────┤
│ up(), down(),     │ 풍선에게 그대로 넘김(위임). 카레이서가       │
│ blow()            │ 자동차에게 "가라"고 시키는 것과 같음         │
├───────────────────┼──────────────────────────────────────────────┤
│ attack(enemy)     │ Player가 직접 판단하는 유일한 메서드         │
└───────────────────┴──────────────────────────────────────────────┘

attack()이 판단하는 순서
if (myHeight == 0)                 → 땅에서는 공격 불가        (8번)
else if (myHeight <= enemyHeight)  → 공격 실패                 (7번)
else                               → enemy.getBalloon().pop()  (6번)
공격은 내 높이와 상대 높이를 둘 다 봐야 해서 풍선 하나만으로는 판단할 수 없습니다. 그래서 두 풍선을 다 아는 Player가 판단하고, 실제로 터트리는 일은 상대 풍선에게 시킵니다.

Balloon.java: 실제 상태

private int height = 0;         // 높이 0 ~ 5
private int count = 3;          // 풍선 개수 0 ~ 3
private int inflateCount = 0;   // 이번 판에 분 횟수 (최대 2)
모든 메서드가 "안 되는 조건 먼저 검사 → 다 통과하면 실행" 순서입니다.

┌─────────────────┬───────────────────┬───────────────────────────┐
│     메서드      │    막히는 조건    │         통과하면          │
├─────────────────┼───────────────────┼───────────────────────────┤
│ up()            │ 높이 5            │ height++ (4번)            │
├─────────────────┼───────────────────┼───────────────────────────┤
│ down()          │ 높이 0            │ height-- (5번)            │
├─────────────────┼───────────────────┼───────────────────────────┤
│                 │ 땅이 아님 → 이미  │ count++, inflateCount++   │
│ inflate()       │ 3개 → 이미 2번    │ (9번)                     │
│                 │ 불었음            │                           │
├─────────────────┼───────────────────┼───────────────────────────┤
│                 │ 이미 0개면        │ count--, 0개가 되면       │
│ pop()           │ 아무것도 안 함    │ height = 0으로 추락 (10,  │
│                 │                   │ 11번)                     │
├─────────────────┼───────────────────┼───────────────────────────┤
│ getHeight(),    │                   │ 값만 돌려줌               │
│ getCount()      │                   │                           │
└─────────────────┴───────────────────┴───────────────────────────┘

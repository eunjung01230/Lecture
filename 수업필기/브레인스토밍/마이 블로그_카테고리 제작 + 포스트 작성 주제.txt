   ↓
VS Code / IntelliJ IDEA

   ↓

   ↓

   ↓

Tomcat

순서	포스트	핵심 내용
00	개발환경 구축 전체 가이드	앞으로 설치할 프로그램이 무엇이고 왜 필요한지
01	Git & GitHub 환경 구축	Git 설치 → Git Bash → 사용자 설정 → GitHub 연결
02	SourceTree 환경 구축	Git을 GUI로 사용하는 이유 → 설치 → GitHub 연결 → 저장소 열기
03	VS Code 환경 구축	설치 → PATH → 터미널 → 확장 프로그램 → 기본 사용법
04	Node.js 환경 구축	Node.js/npm 개념 → LTS 설치 → 버전 확인 → 첫 실행
05	JDK 21 환경 구축	Java/JDK/JRE 차이 → JDK 설치 → PATH → java, javac 확인
06	IntelliJ IDEA 환경 구축	IDE 개념 → 설치 → JDK 연결 → Java 프로젝트 실행
07	Tomcat 환경 구축	웹서버/서블릿 컨테이너 개념 → 설치 → 실행 → localhost 확인

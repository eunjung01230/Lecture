async/await는 실행 순서, try-catch는 예외 처리, Timeout은 대기 시간 문제를 해결하는 수단

callback은 어떤 행동을 할지 미리 정해놓은 것 
이유는 함수의 종료 시점과 호출의 시점이 동일하지 않기 때문에 행동을 전달하는 것  

callback이 전달 callback()이 나오면 실행 

그래서 실행을 할려며 저장-실행 구조가 계속 반복되어야함 

반복되는 것을 약속을 정하는게 promise =결과를 관리 
=============================
문법	의미
new Promise() = Promise 객체 생성
resolve(value) = 일반적인 값으로 작업 성공 결과 전달
reject(error)	 = 작업 실패 원인 전달
.then() = 성공 시 실행할 함수 등록
.catch() = 실패 시 실행할 함수 등록
.finally() = 성공·실패와 관계없이 실행할 함수 등록
=================================
실제 코드가 복잡했지면 반복을 해결해도 promise가 복잡해짐 
해결을 위해 async/await

asyn은 그럼 항상 반환하면 실패한 값도 그대로 반환? catch? 
await는 완료될때까지 일시 중단하고 결과값ㅇ르 기다리면 영원히 안끝날수도 있어? try-catch 필수? 

await의 다른점은 내부는 동기로 운영되지만 외부에있는 다른비동기 함수들은 계속 실행되고있기 때문이야?

============================================================
Callback — 행동 중심

작업이 끝나면 내가 전달한 함수를 실행해 줘.

Promise — 결과와 상태 중심

작업의 상태와 결과를 관리해 줘. 성공과 실패에 따라 다음 행동을 등록할게.

async — 반환 방식

이 함수의 성공과 실패를 Promise 객체로 전달할게.

await — 실행 순서 제어

결과가 확정될 때까지 이 함수의 이후 실행만 중단할게. 다른 작업은 계속 진행해도 돼.

try-catch — 예외 처리

실행 중 실패가 발생하면 어떻게 대응할지 정할게.

Timeout — 대기 시간 제어

일정 시간 안에 결과가 나오지 않으면 대기를 종료하고 실패로 처리할게.

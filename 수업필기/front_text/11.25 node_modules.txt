화면에 대한 전권은 프론트가 담당 더 이상 백엔드는 화면을 리턴받지 않는다 
그냥 컨트롤러 아니고 rest 컨트롤러로 = 페이지를 리턴하는 책임에서 벗어나 , 데이터만을 json으로 return 
페이지를 결정하는 주체는  front 서버가 담당한다 

JS 에서 객체는 key-values 
key-values 이제 제일 중요 진짜 완전 짱 중요 

[event]
   const [form, setForm] = useState({
        username: '',
        email: ''
    });

하나의 객체로 묵어둔다. 
======================================
 setForm({
            ...form,    // 기존 값을 스프레드 문법으로 복사하지 않으면 
                        // form에 묶여있 다른 갑을 수정하면 기존 값이 
                        // 초기화 된다. 
            [e.target.name] : e.target.value
        });

기존 값을 스프레드 문법으로 복사
========================================
const onResetHandler = () => {
        setForm({username : '', email : ''});
    };

# CLAUDE.md

## 프로젝트 개요

풍선을 타고 상대방의 풍선을 터트리는 **2인용 콘솔 턴제 게임** (Java)

- 객체지향 설계 연습용 프로젝트이다.
- 요구사항 → 클래스 후보 도출 → 객체별 메세지(책임) 정의 순서로 설계한다.

## 프로그램 요구사항

```java
/* comment. 프로그램 요구사항 작성
 *   주제 : 풍선을 타고 상대방의 풍선을 터트리는 게임 (콘솔 턴제 게임)
 *   1. 게임은 플레이어 2명(1P, 2P)이 번갈아 가며 한 턴씩 진행한다.
 *   2. 플레이어는 처음에 풍선 3개를 단 채 땅(높이 0)에서 대기한다.
 *   3. 플레이어는 자기 턴에 상승, 하강, 공격, 풍선 불기 중 한 가지 행동만 할 수 있다.
 *   4. 플레이어가 상승하면 높이가 1 올라간다. 이미 최대 높이(5)라면 더 이상 올라갈 수 없다고 안내한다.
 *   5. 플레이어가 하강하면 높이가 1 내려간다. 이미 땅에 있다면 더 이상 내려갈 수 없다고 안내한다.
 *   6. 플레이어가 공격할 때 자신이 상대방보다 높이 있다면 상대방의 풍선 1개를 터트린다.
 *   7. 공격할 때 상대방과 높이가 같다면 50% 확률로 풍선을 터트리고, 상대방보다 낮다면 공격에 실패했다고 안내한다.
 *   8. 땅에 있는 플레이어는 공격할 수 없다. 먼저 하늘로 떠올라야 한다.
 *   9. 플레이어는 땅에 있을 때만 풍선을 불어 1개 추가할 수 있다. 이미 풍선이 3개라면 더 불 수 없으며, 풍선 불기는 한 판에 2번까지만 할 수 있다.
 *   10. 풍선이 터지면 풍선 개수가 1 줄어들고, 남은 풍선 개수를 안내한다.
 *   11. 풍선이 모두 터진 플레이어는 땅으로 추락하고, 더 이상 행동할 수 없다.
 *   12. 한 플레이어의 풍선이 모두 터지면 게임은 끝나고 승자를 안내한다.
 *  */
```

## 객체 설계

```java
/* comment. 은/는 , 이/가 <- 이 키워드 앞 단어가 대부분 클래스 후보이다.
 *   여기서 필요한 객체는 게임, 플레이어, 풍선 객체이다.
 *   게임이 수신할 수 있는 메세지는 게임이 해야 할 일과 동일하다.
 *   1. 게임을 시작해라
 *   2. 턴을 넘겨라
 *   3. 승패를 판정해라
 *   4. 게임을 종료해라
 *   플레이어가 수신할 수 있는 메세지는 플레이어가 해야 할 일과 동일하다.
 *   1. 상승해라
 *   2. 하강해라
 *   3. 상대방을 공격해라
 *   4. 풍선을 불어라
 *   풍선이 수신할 수 있는 메세지는 풍선이 해야 할 일과 동일하다.
 *   1. 떠올라라
 *   2. 내려가라
 *   3. 부풀어라 (풍선 개수 증가)
 *   4. 터져라 (풍선 개수 감소)
 *   5. 남은 풍선 개수를 알려줘라
 *  */
```

## 클래스 구성 (`src/game/run/`)

| 클래스 | 역할 | 필드 | 메서드 |
|---|---|---|---|
| `Application` | 입력을 받아 객체에게 메세지를 보낸다 | - | `main()` |
| `Game` | 턴 순서와 승패 판정을 관리한다 | `player1`, `player2`, `turn`(1 또는 2) | `Game(Player, Player)`, `start()`, `getCurrentPlayer()`, `getOpponent()`, `printStatus()`, `isOver()`, `printWinner()`, `nextTurn()` |
| `Player` | 풍선을 타고 움직이며 상대를 공격한다 | `name`, `balloon` | `Player(String)`, `getName()`, `up()`, `down()`, `attack(Player enemy)`, `blow()`, `getBalloon()` |
| `Balloon` | 높이와 풍선 개수를 가진다 | `height`(0 ~ 5, 처음 0), `count`(0 ~ 3, 처음 3), `inflateCount`(불기 횟수, 최대 2) | `up()`, `down()`, `inflate()`, `pop()`, `getHeight()`, `getCount()` |

## 한 턴의 진행 순서 (`Application`의 `while`)

1. `game.getCurrentPlayer()`, `game.getOpponent()` 로 이번 턴 플레이어와 상대 확인
2. `game.printStatus()` 로 두 플레이어 상태 출력
3. 행동 입력 → `switch`
   - 1 : `now.up()` / 2 : `now.down()` / 3 : `now.attack(enemy)` / 4 : `now.blow()`
   - 9 : 게임 종료 (`return`)
   - 잘못된 번호 : `continue` (턴이 넘어가지 않음)
4. `game.isOver()` 이면 → `game.printWinner()` → 반복 종료
5. 아니면 `game.nextTurn()`

## 설계 원칙

- **플레이어 ↔ 풍선** 관계는 카레이서 ↔ 자동차 관계와 같다.
  플레이어는 메세지를 받으면 실제 상태 변경을 풍선 객체에게 위임한다.
- **풍선** 객체가 상태(`높이`, `풍선 개수`)를 가진다.
- "더 이상 ~할 수 없다" 류의 요구사항(4, 5, 8, 9번)은 상태값으로 조건을 먼저 검사한 뒤 안내 메세지를 출력한다.
- 풍선이 0개가 되면 `height = 0` 으로 만들어 추락시킨다. (11번)
- **게임** 객체는 두 플레이어를 모두 알고 있으며, 턴 순서 관리와 승패 판정을 담당한다.

## 코드 작성 규칙

- 소스 코드는 `src/game/run/` 아래에 작성한다.
- 요구사항 주석(`/* comment. ... */`)은 위 형식을 그대로 유지한다.
- 필드는 `private`으로 선언하고, 상태 변경은 메세지(메소드)를 통해서만 한다.
- 콘솔 입력은 `Scanner`를 사용한다.
- 작성 순서 : `Balloon` → `Player` → `Game` (작은 부품부터, 만들 때마다 `Application`에서 시험)
